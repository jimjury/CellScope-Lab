# CellScope Academy | 从科研问题到可复现实验

版本：2026-11-08 · v0.4。本文给出平台内教程的科学边界与研究实施顺序，内容为独立编写，借鉴公开的时序和电池研究最佳实践。各模块是教学资料而非替代论文、数据原作者的实验定义。

## 1. 从任务定义开始，而不是从模型名字开始

| 任务 | 目标值 | 单位 / 边界 | 必须说明的问题 |
|---|---|---|---|
| SOC | 当前荷电状态或下一采样时刻荷电状态 | 0–1 分数或 0–100% | 使用额定容量还是可用容量？初始状态与库仑计量基准是什么？预测的是第 W 还是第 W+1 个点？ |
| SOH | 相对容量、相对内阻等健康指标 | 维度依原始定义，常见容量比 0–1 | 采用初始容量、额定容量或早期参考容量？容量测量是何种协议？ |
| RUL | 距离 EOL 的剩余循环数/时间 | cycles / hours | EOL 阈值及标签是否由实际观测确定？未结束实验的电芯属于删失数据 |
| 分类故障 | 故障类别或风险概率 | 0/1、多个类别、风险评分 | 正负例定义、误报代价、标签取样时刻和事件发生时间是什么？ |

固定实验目标不同，数据划分和衡量指标就不同。“在同一电芯上测未来”不等于“在未知电芯上泛化”。“分类指标”不能直接给连续回归结果排名。

## 2. 数据来源与实验身份证

建立 `source_manifest` 概念：机构、来源链接/DOI、数据版本、许可/限制、化学体系、圆柱/软包形式、电池编号、容量单位、充放电工况、温度、数据是否含实验终点、时钟采样与缺失报告、SHA256。数据集目录记录与真实下载的 CSV/MAT/PKL 不同；链接存在也不证明文件完整或许可可再分发。

本网页的 ADV 目录使用作者自己维护的 [ADV·BATTERY](https://github.com/jimjury/ADV-BATTERY-Dataset-Collection) 公共 JSON 目录，在线拉取，无原始测量数据；断网显示明确的 12 项来源备用视图。2026-11-07 的目录统计约 114 条资源、111 条文献/目录记录；实际数量以在线返回的数据为准。

## 3. 从原始时序到可训练数据

1. 解析单位与时间戳：秒、毫秒、采样序号都可能出现在“Time”列，未确认采样间隔前不要把每 10 行取 1 行宣称为 1 Hz。
2. 去重与时间排序：明确重复记录是设备重发还是独立测试；谨慎采用“保留首行”等策略并计数。
3. 分阶段：充电 CC/CV、放电、静置、脉冲和保护暂停不可盲目混入；电流正负方向由仪器定义。
4. 缺失和无效：NaN/Inf、单位不一致、超出物理范围、异常脉冲分别记录；不能以“曲线更好看”为理由删除真实工况。
5. 时间断点：长缺口应切成独立片段，训练窗口不能跨越；短缺口能否插值取决于采样原理和实验目标。不得对在线未知的未来点插值并声称因果预测。
6. 采样/滤波：下采样前应考虑抗混叠和脉冲信息，行抽取≠等时间采样；SOC 真实标签本身需先核验物理定义。
7. 容量/退化：积分电流和设备 Ah 列可能有偏差、重置、充放电方向变化；请明确容量绝对值/起点/循环分母，不能强制最后 SOC 为 0 而不说明。
8. 先拆分独立研究单位，再在各分区造滑动窗，所有标准化、PCA、特征选择和缺失填补器仅 fit 训练折。

当前 Python CLI 确认支持电池级、SOC 循环级分组；尚未实现通用时间切分或留一工况全流程。网页时间划分与推荐器均有“教学演示”标记。

## 4. 模型从简单基线到可解释深网

优先 Mean / Linear / Ridge / 传统树，再对比 MLP→RNN/GRU/LSTM→局部 CNN→Transformer→混合架构。每增加一个模块，记录为什么需要、计算开销是否值得、是否真的缓解了验证误差或低 SOC 误差。

神经网络维度以 `[Batch,Window,Features]` 为最常见输入，在 `Conv1d` 中需要 `[Batch,Channels,Length]`，在多头注意力和 PyTorch 版 RNN 中须检查 `batch_first`。残差分支相加要求形状一致；BiLSTM 在**已观测历史窗口内部**双向编码不等于预测时读取未来输入。单层 `nn.LSTM(...,dropout=p)` 的内置 dropout 通常不会启用，应单独加 `nn.Dropout` 处理。

模型激活函数 ReLU / GELU / sigmoid / tanh 会改变梯度传播和输出范围。BN 的统计量依 batch 分布且训练/推理状态不同；LN 是样本内特征归一。Adam/AdamW 正则化、weight decay、learning-rate schedule、梯度裁剪都应作为明确记录的可控因素，不可把某个超参数默认成普适最优。

## 5. 评价与统计证据

连续回归：MAE、RMSE、Bias、R²、按目标范围归一化的 NRMSE。SOC 还需按真实 SOC 分组（比如 0–20%）统计分组 RMSE 和 N；SOH 报告容量参考定义；RUL 报告 cycles/hours 及失效/删失情况。MAPE 在零 SOC 下失效，不能只因低 SOC 误差大就对全局报告 MAPE。

分类：TP、TN、FP、FN，Precision/Recall、F1、Specificity、Balanced Accuracy、MCC、ROC-AUC。ROC-AUC 用连续风险分数排序、仅凭一个混淆矩阵无法得出；类严重不平衡时应考虑 PR 曲线/PR-AUC 和阈值/校准成本。ROC-AUC 需同时有正负例。图表应附数据定义和阈值。

训练只使用训练与验证决定架构、优化器和最佳权重；完整测试只进行最终报告。发表精度比较应固定数据集版本、独立电芯/温度身份、切分名单、预处理、随机种子和计算预算，并呈报均值 ± 标准差及置信度/失败案例，拒绝在测试集反复调参数。

## 6. 网站模块与可交互功能

- 四阶段课程卡：单击展开解释，与数据→模型→评价→优化学习路径对应。
- 时序问题诊所：16 种风险，可搜索、按优先级筛选，查看原因/对策。
- 划分决策工坊：按 SOC/SOH/RUL/分类和科研目标给出方案，交互可设 `N/W/gap` 演示窗口数量，切分原始序列在前。
- 22 个模型源码阅读：从本仓库真实 Python AST 提取代码段，保留源文件 SHA256，区分构造、前向和公共训练逻辑。代码为片段，不能脱离完整文件直接运行。
- 25 个组件知识卡及激活函数曲线；回归/二分类指标计算器；9 道可重做练习。
- 右下角 Volt：离线关键词模板助手，不接任何远程生成式 AI 接口。入口占据保留页面边缘，展开的内容是正文区域面板而非覆盖浮窗。
- 中英文内容切换与主题切换；默认亮色。

## 7. 保留的边界

网站不会在浏览器中训练深度模型、不存储用户输入的科研数据、不自动下载原始电池实验文件、不声称论文复现或自动认证数据许可。Python 实验后端需用户准备符合文档字段的数据，训练结果 JSON 可导入网页分析。完整浏览器点击测试需要可正常导航页面的 Chromium/Firefox，当前管理员策略阻止浏览器访问 URL，因此测试报告必须明确标注这一项未完成。
