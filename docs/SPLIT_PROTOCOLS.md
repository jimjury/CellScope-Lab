# 时序划分、留一法、泄漏预防 / Time-series splits and leakage

## 问题一：要证明什么能力？

| 目标 | 推荐切分的最小独立单位 | 可做的验证 | 错误解读 |
|---|---|---|---|
| 未见过的电池/化学体系 | `cell_id` 或化学体系独立电芯 | GroupShuffleSplit、GroupKFold、留一电芯 | 同电芯循环拆到 train/test 后宣称新电池泛化 |
| 同一电芯、同一时序的未来 | 时间前向连续区段，必要时 embargo/purge | expanding/rolling time split | 随机打乱重叠滑窗再划分，会重用几乎相同序列 |
| 训练电芯已知但循环未见 | `cell_id + cycle_index` | 留一循环 / 按循环顺序向未来 | 留一循环≠留一电芯 |
| 未见温度、工况或倍率 | `condition`、`temperature` 整组 | leave-one-condition-out | 源/目标同电芯时不能视为新电芯独立测试 |
| 完整 SOH/RUL 轨迹泛化 | 完整电芯及其全部循环 | 电芯级 holdout、嵌套分组 CV | 先用完整失效终点构造特征后再拆分 |

## 先划分，再滑窗

例如原始 2000 点、训练比例 70%、验证 15%、测试 15%、历史窗口 W=64、边界隔离 gap=64：

- train 原始点 `[0,1400)`；有效下一步预测窗口数 `1400-64=1336`；
- 训练→验证隔离原始点 `[1400,1464)`；
- validation 原始点 `[1464,1700)`；可用 `236-64=172`；
- 验证→测试隔离 `[1700,1764)`；
- test 原始点 `[1764,2000)`；可用 `236-64=172`。

这是一种**严格隔离的教学例子**，不是所有电池任务都需要 `gap=W`。在标签延迟、输入特征计算跨边界、序列重叠等情况，gap 应通过信息可用时间与预测 horizon 分析设置。绝不能以测试数据拟合归一化参数，也不能让测试条件影响最佳 epoch。

### 留一法的对象必须写清楚

- LOBO = leave-one-battery-out：完整电芯留出，训练侧另设验证。
- LOCO = leave-one-condition-out：工况/温度留出（同电芯可重复，需明确独立性）。
- LOCO (cycle) 在部分文章中也可指 leave-one-cycle-out，缩写含义冲突，应写全称。
- LOSO (subject) 在时间序列中常指 leave-one-subject-out，不自动代表“电芯”。

## 禁止的泄漏路径

1. 同一电芯或者同一连续时序的重叠窗口随机分到训练和测试。
2. 对完整数据 fit 标准化/MinMax/PCA/插补后再划分。
3. 用测试集 RMSE 保存最优权重或反复搜索超参数。
4. 根据每个测试文件的“全循环最大容量”作为在线输入时的特征，等价于已知未来完整放电容量。离线标签可以使用未来完整容量，但必须明说，且不能把它作为模型特征。
5. 使用目标电芯终止寿命生成 RUL 标签，但未来未观测到 EOL 的被删失电芯被强行当成已故障。
6. 用未来未观测的数据进行平滑或插值，然后声称是实时估计。
7. 共享电芯、实验批次、工况片段的身份被重命名，造成“看似独立”样本。

## 评估报告的最低清单

数据集版本/DOI、原始哈希、切分单位及成员、预测起止时点、窗口长度与步长、输入特征、标签时间对齐、SOC/SOH 容量定义、归一化 fit 集合、选权重依据、数值单位、分组指标和置信度。

## 当前代码能力

Python `cellscope/split.py` 实现电池级/循环级划分；RUL/SOH 只允许电池级划分，且数据标签仍需外部来源支持。网页的时间切分模拟、留一电芯/工况问诊是科学教学，**未映射到新的 CLI 执行选项**。升级模型协议时不能把可视化方案写成已经运行的训练模式。
