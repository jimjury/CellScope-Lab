CELLSCOPE LAB · USER GUIDE

从数据导入到可信实验结果

本页适用于静态 HTML 和 GitHub Pages 访问。网站展示概念、生成配置与读取实验结果；实际模型训练请在项目根目录执行 Python CLI。

01 / 安装与快速体验

python -m pip install -e .
python -m cellscope demo --out examples/generated/synthetic.csv
python -m cellscope train --config configs/soc_demo.json --out runs/soc_demo

默认示例数据由代码生成，不是公开数据集。结果位于 runs/soc_demo/metrics.json，可在主页“结果分析室”中导入。

02 / 真实数据的字段

字段含义
cell_id, cycle_index电池与循环唯一身份
time_s时间（秒）
voltage_v, current_a, temperature_c传感器输入
soc / soh / rul_cycles根据任务选择的真实标签

程序支持 Voltage_V、Current_A、T、SOC 等别名，但不会自动推断未知标签的科学定义。

03 / 如何保证不发生数据泄漏

先按电池标识划分训练、验证与测试集合，再分别形成窗口；标准化/最大最小统计量只由训练窗口拟合。SOC 以连续 W 个 V/I/T 点预测下一时间点 SOC；RUL 只接受具有明确寿命终点的标签，不把文件最后一行当作已知失效。

04 / 模型与实验配置

目前有 22 种可训练模型（9 种统计/传统机器学习、13 种神经网络），包括 LSTM、BiGRU、DLinear、TCN、CNN-GRU、PatchTST-lite、iTransformer-lite 等。后两者是简化的论文启发实现，不是原论文完整模型。全部安装可用 python -m pip install -e '.[all]'。网页可通过“实验配置台”下载 JSON；把真实 CSV 路径填入 data.path 后运行。

05 / 多模型对比

python -m cellscope models
python -m cellscope compare --config configs/soc_demo.json --models mean,ridge,mlp,gru --out runs/compare

在主页底部导入 runs/compare/comparison.json，展示多个模型相同划分下的验证与测试误差。排序以验证 RMSE 为依据，测试误差不用于选模型。

06 / 阅读结果

每次运行生成指标 JSON、原始数据 SHA256、分组清单、归一化参数，以及三个预测 CSV 文件。结果中含单电池误差，SOC 另提供低 SOC 段的误差统计。浏览器本地读取 JSON，不会把数据上传到服务器。

07 / 系统学习学院与模型源码

新版首页增加四阶段 16 节课程、16 类时序质量诊断、可调的时间前向划分、22 个模型真实源代码片段及 25 个神经网络基础概念。源码来自 cellscope/models.py 的构造、前向与公共训练函数截取，展示内容不能脱离上下文单独执行。选模型、切换代码标签、复制片段以及链接完整源码均有对应交互。

08 / 指标计算与防止误用

连续 SOC / SOH / RUL 应报告 MAE、RMSE、R²、Bias 等；SOC 还应报告低 SOC 段误差，并约定 SOC 的 0–1 量纲。使用同一测试协议且未以测试指标选模型，才能比较模型。Accuracy、F1、ROC-AUC 专用于有清晰类别标签的故障/安全分类，不能直接用于连续 SOC 回归。分类计算器仅是网页教学功能：Python CLI 当前不训练分类器。

09 / 数据划分怎样选

未见电池的泛化应采用电芯级互斥分组或留一电芯；已知电芯的未来预测可选择时间顺序训练、验证、测试，必要时设置隔离区；未见循环但仍属于同一电芯的实验不能声称是跨电芯独立测试。选择“留一工况/温度”之前，必须检查相同电芯是否同时存在于训练和测试。网页划分决策是教程，Python CLI 目前仅有 battery/cycle 两种拆分单位。

10 / ADV·BATTERY 目录联动及 Volt

网页在线读取 ADV·BATTERY 的公开数据集与论文 JSON，提供任务筛选、关键词、来源详情及引用入口，连接失败时回退到内置来源卡片。网站不会静默下载实验原始数据，也不会默认拥有第三方数据的再分发许可。右侧 Volt 小精灵采用固定知识模板与关键词导学，不连接在线 LLM，不存储聊天记录；展开为正文中的独立面板，不覆盖图表。

11 / 语言、主题与访问

首页默认浅色，可通过顶部按钮切换暗色；中英文菜单同时切换静态内容与系统学习卡。网站以浏览器本地运行的结构演示和计算为主，不会代替实际 Python 训练与公开数据的人工核验。

12 / 测试与限制

自动化检查包含 Python/JS 单测、代码解析、资源存在与控件连线静态审计。该执行环境 Chromium 受管理员策略限制，完整跨浏览器真实点击和截图验收未完成，不能假称已通过。查看仓库 WEB_QA.md 及 GitHub Actions 核查实际运行状态。

13 / 项目边界

网页版的模型动画是独立绘制的结构示意；信号处理曲线是确定性演示，不是真实传感器数据。公开数据集目录仅提供来源，不包括数据内容。完整复现原论文仍需要额外的数据下载、元数据核对与专用适配器。
