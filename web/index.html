    图片里的 Accuracy、Precision、Recall、F1、AUC 适合故障分类；SOC/SOH/RUL 连续估计需要 MAE、RMSE、R²、Bias 等。动手输入数字，所有指标即时计算，不编造模型性能。

    REGRESSION
    连续值预测误差计算器
    REAL CALCULATION
    数组长度必须相同；SOC/SOH 用 0–1 数值时，RMSE×100 表示百分比点（pp），不是相对百分比。SOC 低值段按真实 SOC≤0.2 筛选，统计独立子集误差和 N；NRMSE 以真实值范围归一化。
    MAEmean |y−ŷ| · 对偏差直观
    RMSE√mean(y−ŷ)² · 强调大误差
    R²1−SSres/SStot · 可为负
    MAPE接近 0 时不稳定 · 显示有效项数
    
          
    CLASSIFICATION
    混淆矩阵 + ROC-AUC 计算器
    FAULT / SAFETY ONLY
    行：真实类别 ｜ 列：预测类别
    ROC-AUC 基于连续风险评分计算，不能只用某一阈值下的 TP/FP/TN/FN 反推；数据全为同一类时 AUC 不定义。
